# services

## 用途

业务逻辑服务层，封装复杂的业务逻辑，保持路由处理函数简洁。

## 核心文件

| 文件 | 描述 |
|------|------|
| `__init__.py` | Python 包初始化文件 |

## 子目录

当前无子目录。

## AI Agent 工作指南

### 在此目录工作时

- 为每个业务领域创建服务模块
- 服务函数接收数据库会话作为参数
- 复杂的业务逻辑应封装在服务层
- 服务层负责数据库事务管理

### 测试要求

- 为每个服务函数编写单元测试
- 使用 mock 隔离数据库依赖

### 常见模式

- 服务函数命名：`create_xxx`, `get_xxx`, `update_xxx`, `delete_xxx`
- 接收 `db: Session` 作为第一个参数
- 返回数据库模型或抛出异常
- 使用类型注解明确参数和返回值

## 依赖关系

### 内部依赖

- 依赖 `models/` (数据库操作)
- 被 `api/` 调用

### 外部依赖

- SQLAlchemy

## 服务分类

### 用户服务
- 用户注册、登录、信息更新

### 订阅服务
- 订阅创建、续费、查询

### 兑换码服务
- 兑换码生成、验证、使用

### 隧道服务
- 隧道创建、配置、删除

### FRP 插件服务
- 与 FRP 插件通信
- 同步用户和隧道配置
